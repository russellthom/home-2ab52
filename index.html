Webhook

One-time: in the Shortcuts app make a shortcut with this exact name: Receive Text input → Get Contents of URL = your webhook URL, Method POST, Headers Authorization = Bearer <key> and Content-Type = application/json, Request Body File = Shortcut Input. The key stays in the Shortcut; this page only passes the command.

Commands go straight to the webhook. The server doesn't send CORS headers, so the page usually can't read its reply — presses still go through and show “Sent ✓ (no confirmation from server)”.
